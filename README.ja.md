# PuffiCSS｜軽量な Web アニメーションライブラリ

Web アニメーションのアイデアを集めたライブラリです。標準の HTML、CSS、JavaScript で構築されており、フロントエンドパッケージのインストールは不要です。

## 機能

- マイクロインタラクション、テキスト、登場、背景、ローディング、強調の 6 カテゴリに分かれた、18 種類のオリジナルアニメーション。
- リアルタイムプレビュー、一時停止、再生、および英語・繁体字中国語・日本語のキーワード検索。
- カテゴリ、並べ替え、お気に入り、ランダム表示、使い方ガイド。
- 再生時間、遅延、イージング、アクセントカラー、ループを調整可能。タイプライター効果は固定の `steps` を使用。
- 完全な HTML + CSS、CSS、React JSX、Vue SFC のコピーとダウンロード。
- 同じページで設定の異なるアニメーションを使っても、スタイルが互いに干渉しない構成。
- ループをオフにすると、登場とテキストのアニメーションは最後に表示された内容を維持。
- ライト／ダークテーマ、モバイルナビゲーション、キーボード操作、動きを減らす設定への対応。
- 初期表示は英語。ヘッダーの言語メニューから English、繁體中文、日本語に切り替え可能。
- 言語、お気に入り、テーマの設定は使用中のブラウザに保存。アカウントは不要で、バックエンドや端末間の同期機能はありません。

## アニメーションの使い方

カードの「コードを取得」をクリックし、パラメータを調整して形式を選びます。

| 形式       | 使い方                                                                                                               |
| ---------- | -------------------------------------------------------------------------------------------------------------------- |
| HTML + CSS | 完全な独立ページです。`.html` として保存して開くか、`style` と `body` の内容を取り出して既存のページに組み込みます。 |
| CSS        | HTML + CSS タブの `body` 内のマークアップと組み合わせて使用します。コンテナのクラスはすべて保持してください。        |
| React      | `MotionDemo.jsx` として保存し、インポートして `<MotionDemo />` を使用します。既存の React プロジェクトが必要です。   |
| Vue        | `MotionDemo.vue` として保存し、インポートして `<MotionDemo />` を使用します。既存の Vue プロジェクトが必要です。     |

アニメーションのサンプル自体は CDN に接続しません。サイトのフォントには Google Fonts を使用し、オフライン時はシステムフォントに切り替わります。
